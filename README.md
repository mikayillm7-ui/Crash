# آرنا: راهنمای راه‌اندازی

فایل‌ها: server.js (سرور)، engine.js (منطق بازی‌ها)، public/index.html (صفحه‌ی موبایل)، package.json

## اجرا
node server.js    (Node 18 یا بالاتر) → http://localhost:3000

## متغیرهای محیطی
| نام | توضیح |
|---|---|
| ADMIN_KEY | رمز دلخواه برای بخش مدیریت (الزامی) |
| DATA_DIR | مسیر دیسک دائمی برای data.json (بدون آن با هر ری‌استارت حساب‌ها پاک می‌شود) |
| WEEKLY_BUDGET | سقف پرداخت هفتگی به تومان. صفر یعنی فروشگاه بسته است (پیش‌فرض) |
| POINT_TOMAN_PER_1000 | ارزش ۱۰۰۰ امتیاز به تومان (پیش‌فرض ۱۰۰۰) |
| MAX_USER_WEEK_TOMAN | سقف برداشت هفتگی هر کاربر (پیش‌فرض ۱۰۰٬۰۰۰) |

## مدیریت (با ADMIN_KEY)
- ۳ نفر اول هفته: GET /api/admin/top?key=...
- درخواست‌های برداشت امتیاز: GET /api/admin/requests?key=...
- پرداخت یا رد: POST /api/admin/resolve?key=... با بدنه‌ی {"id":"...","action":"paid"} یا "rejected" (رد، امتیاز را برمی‌گرداند)

## فروشگاه امتیاز: چطور سود تو حفظ می‌شود
- امتیاز با سکه‌ی بازی جداست. سکه هرگز به پول تبدیل نمی‌شود.
- امتیاز فقط از این‌ها می‌آید: تماشای تبلیغ پاداشی (۱)، ۱۰ دور در روز (۵)، دعوت دوستی که ۳۰ دور بازی کند (۲۰) و رتبه‌ی هفتگی (۵۰ تا ۵۰۰).
- هر هفته خودت WEEKLY_BUDGET را از درآمد واقعی تبلیغات همان هفته تنظیم کن، مثلاً ۴۰٪ درآمد. سرور هیچ‌وقت بیشتر از آن تعهد نمی‌کند.
- ارزش امتیاز را این‌طور بسنج: اگر هر نمایش تبلیغ پاداشی برایت X تومان درآمد دارد، هر امتیاز تبلیغی باید کمتر از X تومان ارزش داشته باشد. POINT_TOMAN_PER_1000 را بر همین اساس بگذار.
- شرط‌ها: حساب ۷ روزه، ۱۰۰ دور بازی، حداقل ۵۰۰۰ امتیاز، یک درخواست در انتظار، بررسی دستی قبل از پرداخت.
- اطلاعات کارت در سایت گرفته نمی‌شود. فقط آیدی تماس می‌گیری و پرداخت را خارج از سایت انجام می‌دهی.

## قبل از باز کردن فروشگاه (WEEKLY_BUDGET بیشتر از صفر)
۱. تأیید تماشای تبلیغ را از callback سروری شبکه‌ی تبلیغاتی بگیر. الان سرور فقط محدودیت زمانی دارد و کسی می‌تواند با اسکریپت امتیاز تبلیغ بسازد.
۲. حساب‌های چندگانه و دعوت‌های مشکوک را قبل از هر پرداخت بررسی کن.
۳. از یک متخصص حقوقی بپرس این ساختار (جایزه‌ی نقدی در بازی‌هایی با عنصر شانس) در محل تو مجاز است یا نه.

## تبلیغات
کد شبکه‌ی تبلیغاتی را در تابع showAd و جای بنرها (public/index.html) بگذار. بین هر دو دور انفجار، دو نمایش تبلیغ نشان داده می‌شود.
